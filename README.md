# Laravel Forge Scripts

A collection of recipes and other scripts designed to enhance your Laravel Forge workflow.

## Recipes

Server-level scripts run from Forge's **Recipes** section to provision or maintain a server.

- [Install Docker](recipes/install-docker)

## Scripts

Scripts that replace a site's default **deployment** script in Forge.

- [Atomic Deployment Script](scripts/atomic-deployment)

## Usage

Each script has its own README with installation steps and configuration options. Review any script before running it — these execute with elevated privileges on your servers.
